# GigLift

GigLift is a modern English-language freelance marketplace prototype inspired by the best parts of Upwork, Fiverr, 99designs, Uber-style dispatch, and Temu-style growth loops.

## Current prototype includes

- Modern dark SaaS-style landing page
- Mock job marketplace with category filters
- Freelancer dashboard stats and activity feed
- Membership / level progression system
- Referral rewards and weekly leaderboard
- Mock freelancer cards and platform energy

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy on Render

This repo includes `render.yaml` for static deployment.

- Build command: `npm install && npm run build`
- Publish directory: `dist`
